# 部署前必填清单

**部署前必须完成以下配置，否则服务无法正常运行。**

---

## 1. 环境变量（`.env`）

```bash
cp .env.example .env
vi .env
```

### 必填项

| 变量 | 说明 | 从哪里获取 |
|------|------|-----------|
| `MYSQL_HOST` | MySQL 服务器 IP | 运维/DBA |
| `MYSQL_PORT` | MySQL 端口 | 通常 3306 |
| `MYSQL_DATABASE` | 数据库名 | 通常 `kod` |
| `MYSQL_USERNAME` | MySQL 账号 | 运维/DBA |
| `MYSQL_PASSWORD` | MySQL 密码 | 运维/DBA |
| `REDIS_HOST` | Redis 服务器 IP | 运维/DBA |
| `REDIS_PORT` | Redis 端口 | 通常 6379 |
| `REDIS_PASSWORD` | Redis 密码 | 运维/DBA |
| `JWT_SECRET` | JWT 签名密钥 | 执行 `openssl rand -hex 32` 生成 |

### 选填项

| 变量 | 说明 | 影响 |
|------|------|------|
| `MAIL_HOST` / `MAIL_PORT` | SMTP 服务器 | 不配则验证码只打日志，不发邮件 |
| `MAIL_USERNAME` / `MAIL_PASSWORD` | SMTP 账号密码 | 同邮件服务器配置 |

---

## 2. 数据库建表

```bash
mysql -h<HOST> -P<PORT> -u<USER> -p <DATABASE> < backend/src/main/resources/schema.sql
```

---

## 3. 前环境变量（`frontend/.env`）

如需自定义 KOD Web 端地址：

```env
VITE_KOD_WEB_URL=https://web.kod.xxx
```

---

## 4. 验证

```bash
# 前端
curl http://<服务器IP>/

# 后端健康检查
curl http://<服务器IP>/api/health
# 应返回 {"status":"UP","redis":"UP",...}

# 注册流程
curl -X POST http://<服务器IP>/api/auth/send-code \
  -H 'Content-Type: application/json' \
  -d '{"email":"test@example.com"}'
```
